Rulet.tv · сервер

Подготовьте доступ Yandex Cloud

Нужны сервисный аккаунт с ролями и API-ключ с узкими областями доступа. Затем оба значения добавляются в файл сервера .env.

Сначала скачайте архив

Внутри находятся расширение для Rulet.tv и Python-сервер.

Скачать архив ZIP
Важно: это два разных уровня доступа.
Роли назначаются сервисному аккаунту на каталог, а области действия выбираются отдельно при создании API-ключа.
1

Создайте сервисный аккаунт

  1. Откройте консоль Yandex Cloud и выберите каталог, в котором будет работать сервер.
  2. Откройте Identity and Access Management → Сервисные аккаунты → Создать сервисный аккаунт. Укажите имя, например rulet-tv-voice-assistant; описание можно заполнить по желанию.
  3. В форме создания найдите блок Роли в каталоге, нажмите Добавить роль и добавьте все роли из списка ниже. Так они назначатся аккаунту в выбранном каталоге.
ai.languageModels.userИспользование языковой модели
ai.speechkit-stt.userРаспознавание речи
ai.speechkit-tts.userСинтез речи
resource-manager.viewerТолько чтение сведений о каталоге; входит в проверенный рабочий набор

После добавления ролей нажмите Создать. Если аккаунт уже создан, назначьте ему эти роли в правах доступа выбранного каталога. Роли editor и admin не нужны.

2

Создайте API-ключ с нужными областями

  1. Откройте созданный сервисный аккаунт. Вверху выберите Создать новый ключ → Создать API-ключ. Не выбирайте статический ключ доступа или авторизованный ключ — нужен именно API-ключ.
  2. Описание ключа необязательно. Поле Область действия обязательно: в длинном списке выберите ровно эти три пункта:
  • yc.ai.foundationModels.execute — ответы YandexGPT.
  • yc.ai.speechkitStt.execute — распознавание речи.
  • yc.ai.speechkitTts.execute — озвучивание ответа.

Проверяйте полные названия: не выбирайте похожую область yc.ai.languageModels.execute. Если список закрылся после выбора пункта, откройте его снова и добавьте следующий. Перед созданием проверьте, что выбраны все три области выше.

Срок действия указывать не обязательно. Оставьте поле даты пустым, если ключ не должен автоматически истечь. Если зададите дату, после неё ключ перестанет работать. Нажмите Создать и сразу скопируйте секретный API-ключ: позднее его значение нельзя будет посмотреть. Не отправляйте ключ в чат.
3

Заполните два поля сервера

Скопируйте ID того же каталога. В консоли он показан под названием каталога; в адресе страницы это часть после /folders/.

В распакованном проекте откройте server и создайте или заполните рядом с .env.example файл .env. Например: C:\Users\user\Downloads\rulet-tv-voice-assistant\server\.env.

YC_API_KEY=вставьте_секретный_API-ключ
YC_FOLDER_ID=вставьте_ID_каталога
Если файла .env ещё нет, скопируйте .env.example рядом и заполните его. Не публикуйте и не отправляйте заполненный файл.
4

Запустите проверку загрузки и настройки

Распакуйте ZIP. Нажмите кнопку, чтобы скачать проверяющий скрипт, и положите файл рядом с архивом или с распакованной папкой проекта.

Скачать Python-скрипт проверки

Проверяющий скрипт также приложен в репозитории рядом с этой HTML-инструкцией.

Откройте PowerShell в этой папке и выполните:

py -3.11 .\check_rulet_tv_setup.py

Если ZIP переименован или лежит в другом месте, укажите путь к нему:

py -3.11 .\check_rulet_tv_setup.py "C:\путь\к\архиву.zip"

Скрипт проверит целостность и состав ZIP, наличие файлов плагина и сервера, значения YC_API_KEY и YC_FOLDER_ID без их показа, Python 3.11+, зависимости и ответ локального сервера. Если что-то пропущено, он напишет что именно сделать.

Проверка работает только с файлами на этом компьютере и адресом localhost. Она не отправляет секреты в интернет и не может сама подтвердить права/баланс Yandex Cloud или факт установки расширения в браузер. Эти пункты сверяйте по инструкции выше.
