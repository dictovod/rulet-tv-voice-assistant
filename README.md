# Rulet.tv Voice Assistant

Голосовой ИИ-помощник для видеочата Rulet.tv. Расширение Chromium передаёт входящую речь локальному Python-серверу. Сервер распознаёт её в Yandex SpeechKit, генерирует ответ в YandexGPT и возвращает речь через SpeechKit TTS.

```text
Rulet.tv WebRTC → расширение → ws://127.0.0.1:8765/ws
                                 VAD → SpeechKit STT → YandexGPT → SpeechKit TTS
Rulet.tv WebRTC ← исходящий PCM ← расширение ←───────────────────────────────┘
```

Расширение не начинает звонки и не выбирает собеседников автоматически. Входящий звук обрабатывается сервисами Яндекса; локально аудиозаписи не сохраняются. Перед тестированием предупредите собеседника и получите его согласие.

## Требования

- Windows 10/11, браузер Chromium: Chrome, Edge или Яндекс Браузер (Chrome 116+).
- Python 3.11 или новее. Python 3.12 поддерживается.
- Аккаунт Yandex Cloud с активным платёжным аккаунтом и доступом к YandexGPT и SpeechKit. Запросы к облачным API могут тарифицироваться.

## Настройка Yandex Cloud

В выбранном каталоге создайте сервисный аккаунт и назначьте ему роли:

- `ai.languageModels.user`
- `ai.speechkit-stt.user`
- `ai.speechkit-tts.user`
- `resource-manager.viewer`

Для этого сервисного аккаунта создайте **API-ключ** (не статический ключ доступа и не авторизованный ключ). Укажите области действия:

- `yc.ai.foundationModels.execute` — YandexGPT.
- `yc.ai.speechkitStt.execute` — распознавание речи.
- `yc.ai.speechkitTts.execute` — синтез речи.

Поле даты истечения можно оставить пустым. Секрет API-ключа показывается при создании — скопируйте его сразу. `YC_FOLDER_ID` — ID того же каталога, которому назначены роли.

## Установка и запуск сервера

Откройте PowerShell в папке `server` проекта. Все зависимости нужно установить в отдельную виртуальную среду, а не в глобальный Python:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

В `server/.env` заполните только необходимые значения:

```dotenv
YC_API_KEY=секретный_API-ключ
YC_FOLDER_ID=ID_каталога
```

Не перезаписывайте уже настроенный `.env`. Запустите сервер из папки `server`:

```powershell
.\.venv\Scripts\python.exe main.py
```

Сервер по умолчанию слушает только `127.0.0.1:8765`. Проверка состояния: откройте <http://127.0.0.1:8765/health>; ожидаемый ответ — `{"status":"ok"}`.

> Установка отдельных пакетов командой `python -m pip install fastapi uvicorn` не создаёт `server/.venv` и не устанавливает полный список зависимостей. Используйте `requirements.txt` указанным выше способом.

## Установка расширения

1. Откройте `chrome://extensions` (в Яндекс Браузере — `browser://extensions`) и включите режим разработчика.
2. Нажмите **Загрузить распакованное расширение** и укажите папку `extension`.
3. Запустите сервер и откройте Rulet.tv.
4. В меню расширения включите автоответчик, выберите режим и оставьте адрес сервера `ws://127.0.0.1:8765/ws`.
5. Обновите вкладку Rulet.tv и щёлкните по странице один раз. Разрешите доступ к микрофону, если браузер запросит его; видеочат запускайте вручную.

Режимы: `Отвечать голосом` (`auto`) и `Только слушать` (`listen`). Опция проигрывания через динамики включена по умолчанию; это тот же TTS-поток, дополнительного запроса к SpeechKit нет.

## Конфигурация и диагностика

- `server/config.yaml` — адрес и порт сервера, модель (`yandexgpt-lite/latest` по умолчанию), параметры VAD, STT/TTS и диалога.
- `server/system_prompt.txt` — системная инструкция модели.
- `server/.env` — секреты; не добавляйте его в Git.
- `GET /health` — проверка HTTP-сервера; `WS /ws` — поток управления и аудио между расширением и сервером.
- `server/test_client.py` — необязательный тест сервера без браузера. На вход нужен WAV: 16 кГц, mono, PCM 16-bit.

Пример теста из папки `server`:

```powershell
.\.venv\Scripts\python.exe test_client.py .\question.wav --mode auto --out .\reply.wav
```

Чтобы ограничить доступ к WebSocket, в `config.yaml` можно указать `allowed_extension_ids` после установки расширения и/или задать `auth_token`. При настройке токена тот же токен нужно добавить к адресу сервера в расширении как `?token=...`. Не включайте `allow_any_origin` на рабочем компьютере с облачным ключом.

## Перед публикацией в GitHub

Добавьте секреты и локальные файлы в `.gitignore`:

```gitignore
server/.env
server/.venv/
**/__pycache__/
*.py[cod]
server/reply.wav
```

В репозитории оставляйте только `server/.env.example` с пустыми значениями. Никогда не публикуйте API-ключ, заполненный `.env` или WAV-файлы с частными разговорами.
